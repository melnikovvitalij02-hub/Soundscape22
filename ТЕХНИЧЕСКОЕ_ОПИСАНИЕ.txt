   SOUNDSCAPE PRO — ТЕХНИЧЕСКОЕ ОПИСАНИЕ ПРОЕКТА
   (для выступления / презентации)
═══════════════════════════════════════════════════

1. ЧТО ЭТО ЗА ПРОЕКТ
───────────────────
Soundscape Pro — музыкальная социальная платформа с элементами
геймификации. Пользователи могут слушать музыку, общаться в чате
и личных сообщениях, играть в аркадные игры, зарабатывать XP и
монеты, участвовать в PvP-битвах, состоять в кланах и сообществах.

2. ТЕХНОЛОГИЧЕСКИЙ СТЕК
───────────────────────

ФРОНТЕНД:
  • React 18 + TypeScript — основной фреймворк
  • Vite 5 — сборщик проекта и dev-сервер
  • Tailwind CSS — система стилизации (utility-first)
  • Lucide React — библиотека иконок
  • HTML5 Canvas + requestAnimationFrame — рендеринг игр (2D)

БЭКЕНД:
  • Supabase (PostgreSQL) — база данных
  • Supabase Auth — аутентификация (email/пароль)
  • Supabase Realtime — обновления в реальном времени (WebSocket)
  • Supabase Storage — хранение файлов (аватары, обложки, архивы)
  • Row Level Security (RLS) — защита данных на уровне базы

ХОСТИНГ:
  • Netlify — статический хостинг фронтенда
  • Supabase Cloud — хостинг базы данных, API и realtime
  • Регион: EU Central (Франкфурт)

3. ЯЗЫКИ ПРОГРАММИРОВАНИЯ
────────────────────────
  • TypeScript — основной язык (фронтенд + типы)
  • SQL — миграции и политики безопасности в базе данных
  • JavaScript — рантайм сборки (Node.js / Vite)

4. КЛЮЧЕВЫЕ ФУНКЦИИ
───────────────────

АУТЕНТИФИКАЦИЯ:
  • Регистрация и вход по email/паролю
  • Гостевой режим (без регистрации, данные в localStorage)
  • Сессии через Supabase Auth

СОЦИАЛЬНЫЕ ФУНКЦИИ:
  • Общий чат с realtime-обновлением
  • Личные сообщения с индикаторами прочтения (галочки)
  • Профили пользователей с аватарами, уровнем, XP, монетами
  • Статус активности: "В сети" / "был(а) недавно" (на основе
    времени последней активности, heartbeat каждые 20 сек)
  • Сообщества и кланы
  • Истории (Stories) с поддержкой видео

МУЗЫКАЛЬНЫЕ ФУНКЦИИ:
  • Поиск музыки
  • Чарты
  • Плейлисты
  • Бит-секвенсор (создание ритмов)
  • ИИ Студия
  • Автомикс
  • Караоке
  • Стримы

ГАЙМИФИКАЦИЯ:
  • 5 аркадных игр (Змейка, Asteroid Blaster, Space Invaders,
    Pac-Man, Stellar Reactor)
  • Награды: XP и монеты зачисляются автоматически
  • PvP-битвы
  • Ежедневные награды
  • Сезонные события
  • Достижения
  • Система уровней (500 XP = 1 уровень)

ТЕМЫ:
  • Несколько цветовых тем (светлая, тёмная и др.)
  • Переключение на лету, сохранение выбора

5. БЕЗОПАСНОСТЬ
──────────────
  • Row Level Security (RLS) на всех таблицах
  • Пользователи видят только свои данные (auth.uid() проверки)
  • 4 политики на каждую таблицу (SELECT, INSERT, UPDATE, DELETE)
  • Анонимный доступ ограничен (только для поиска профилей)

6. REALTIME
──────────
  • Supabase Realtime через WebSocket
  • Общий чат — обновление сообщений без перезагрузки
  • Личные сообщения — уведомления о новых сообщениях
  • Счётчик непрочитанных сообщений в боковом меню

7. СТРУКТУРА ПРОЕКТА
───────────────────
  src/
    components/  — переиспользуемые компоненты (Sidebar, AuthScreen и др.)
    context/     — React контексты (Auth, Theme)
    lib/         — конфигурация Supabase клиента
    pages/       — страницы приложения
    App.tsx      — корневой компонент с роутингом
    main.tsx     — точка входа

  supabase/
    migrations/  — SQL миграции (схема, RLS, переводы)

  public/       — статические файлы (аватары, обложки, _redirects)

8. БАЗА ДАННЫХ — ОСНОВНЫЕ ТАБЛИЦЫ
────────────────────────────────
  • profiles        — профили пользователей (username, xp, level, coins,
                      avatar, bio, last_seen)
  • chat_messages   — сообщения общего чата
  • private_messages — личные сообщения (sender, recipient, read)
  • game_scores     — рекорды в играх
  • clans           — кланы
  • communities     — сообщества
  • stories         — истории (с поддержкой видео)
  • achievements    — достижения
  • daily_rewards   — ежедневные награды
  • seasonal_events — сезонные события

9. ДЕПЛОЙ
─────────
  • Сборка: npm run build → папка dist/
  • Деплой: dist/ загружается в Supabase Storage,
    оттуда раздаётся через Netlify
  • _redirects файл — корректная работа SPA-роутинга

10. ИТОГО
─────────
  Фронтенд: React + TypeScript + Vite + Tailwind CSS
  Бэкенд:   Supabase (PostgreSQL + Auth + Realtime + Storage)
  Хостинг:  Netlify (фронтенд) + Supabase Cloud (база + API)
  Языки:    TypeScript, SQL, JavaScript
